# 共用加点技能 & 德鲁伊小熊背包

## 共用加点的技能（邪影芳灵）

邪影芳灵的大招在数据里有两条：`dark_willow_bedlam`（作祟）和
`dark_willow_terrorize`（恐吓），它们其实是同一个技能槽，点任意一个两边一起升级。

- 名称数据不变，两条都保留；
- `TimelineBuild.vue` 里用 `ABILITY_GROUPS` 把它们合并成一行：`作祟 / 恐吓`；
- 等级 = 两个技能在加点序列里的次数之和，所以只点了「作祟」也会正确显示 `2/3`；
- 只要组里任意一个被点过，这一行就会显示（不会因为只点了「恐吓」而消失）；
- 序号条仍按真实加点顺序显示，点的是哪个就高亮哪个序号。

以后遇到同类“一个技能槽多条记录”的英雄，往 `ABILITY_GROUPS` 里加一组即可。

## 德鲁伊：本体 + 小熊两套背包

### 数据

回放解析（`java/MatchJsonMain.java`）现在会：

- 找到 `CDOTA_Unit_SpiritBear` 实体（注意不是 `CDOTA_Ability_LoneDruid_SpiritBear`）；
- 读取它的 `m_hItems` 0–5、6–8、16 槽，生成独立的 6+1+3 背包快照；
- 输出到 `focus.bearItems`（与本体 `focus.items` 同结构）。

前端 `TimelinePlayer` 增加：

- `bearInventorySnapshots`：小熊的 6+1+3 快照；
- `bearInventoryExact`：是否拿到真实快照；
- `inventoryAt(player, sec, 'bear')`：按时间取小熊背包。

### UI

- 「此刻背包」拆成两组：`本体` 和 `小熊`，各自 6 装备栏 + 1 打野装备 + 3 背包；
- 出装路线仍然只有一条，回放里的购买（无论最终在小熊还是本体身上）都进同一条路线；
- 没有回放数据时，小熊背包显示提示“需要高级分析（回放）”；
- 快照里出现但名称表还没收录的新物品（例如 `item_guardian_shell`）也会显示，不再被过滤掉。

### 已验证

- 比赛 9074689290（独行德鲁伊），回放解析出 21 个小熊背包快照；
- 20:00：本体 9 格（含打野装备），小熊 1 格（打野装备）；
- 26:00：本体 3 格，小熊 4 格（神杖 / 雷神之锤 / 电锤 / 动力鞋）+ 打野装备；
- 出装路线 32 个节点，包含小熊身上成型的神杖、雷神之锤、银影之刃等。

调试入口：URL 加 `replay=1` 会直接加载回放解析（不调用 AI），方便核对背包。
