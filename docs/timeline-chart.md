# 走势图与出装轨（弹窗版）

## 走势图：Chart.js

- 依赖：`chart.js@4.6.1`（`ui/package.json` 已登记），用官方 tarball 直接落进 `ui/node_modules`，
  没有动现有 npm 依赖树；
- `ui/src/components/TimelineChart.vue` 改为 Chart.js 的 `line` 图：
  - 线性 X 轴（分钟刻度 `0m / 7m / …`）+ 紧凑 Y 轴；
  - 内置图例（可点击隐藏某条线）、`index` 模式 tooltip（悬停显示时间 + 各角色数值）；
  - 自定义插件画当前时间游标虚线；
  - 点击画布任意位置 → `seek`，和图例、滑条联动；
  - 网格/文字颜色从 CSS 变量读取，浅色/深色主题切换时重建图表；
  - 容器高度用 `--chart-h` 控制，宽布局下自动拉伸填满左列。

## 出装轨

- 只显示**分析对象**一行（对位角色的购买记录不再画在出装轨里，仍可在图表里对比经济）；
- 占满弹窗整行宽度，单个角色的时间轴更舒展；
- 出装轨显示**所有购买**：消耗品、守卫、榴弹、诡计之雾、显隐之尘、图纸、合成前散件；
- 合成品显示为「小件 → 成品」：小件 12px、成品 24px 金色边框；散件/消耗品 18px；
- 同一时间点的多个购买纵向堆叠；同种物品 10 秒内合并，图标右下角显示数量；
- 仔细观察守卫：`item_ward_observer`（侦查守卫/假眼）与 `item_ward_sentry`（岗哨守卫/真眼）使用不同图标，悬停名称会标注假眼/真眼；
- 「此刻背包」显示为 6 装备栏 + 1 打野装备 + 3 背包，只在高级分析（回放快照）显示；
- 走势优先使用回放 5 秒采样（净经济/补刀/经验/等级/KDA/英雄伤害），没有回放时退回 OpenDota 分钟点；
- KDA 与英雄伤害来自 PlayerResource 官方结算，包含德鲁伊小熊、狼、佣兽等召唤物；战斗日志只作事件明细，召唤物本体击杀会在 prompt 中单独标注；
- 承伤前五按战斗日志的「英雄本体受击」统计；PlayerResource 没有 Damage Taken 字段，小熊/召唤物自身承伤暂不并入。

## 宽布局调整

- 出装轨在弹窗顶部独占一行；
- 下方两列：左侧走势图（`flex:1` 拉伸），右侧「同位置结论 + 技能与天赋」；

## 时间轴吸顶（亚克力）

- 时间滑条用 `position: sticky; top: 0` 固定在弹窗滚动区顶部；
- `.modal-body` 取消顶部 padding，由 `.scrubber` 自己留出 14px（小屏 12px）间距，
  吸顶时正好贴住弹窗头部下沿，不会露出内容；
- 视觉：随主题的亚克力——深色主题 `rgba(16,33,25,.62)` 深色玻璃、浅色主题白色 80%，配 `backdrop-filter: blur(18px) saturate(160%)`；
- 源码只写 unprefixed 的 ackdrop-filter，由构建自动补 -webkit- 前缀；
  如果手写两份，CSS 压缩会把 unprefixed 合并掉，Chromium 里 ackdrop-filter 会变成 
one，模糊不生效；
- 未滚动时无边框、无阴影（`border-color: transparent; box-shadow: none`）；
- 滚动超过 2px 时给 `.modal-body` 加 `scrolled` 类，0.3s 过渡出现边框与悬浮阴影，
  滑回顶部自动淡出；
- 文字/播放键/滑条轨道用 `--scrub-*` 变量：深色玻璃配浅色字，白色底配深色字；
- 回归脚本会校验：浅色底 `rgba(255,255,255,0.8)` + 深色字、深色底 `rgba(16,33,25,.62)` + 浅色字、顶部无阴影、滚动后出现阴影、
  滑条顶部与滚动区顶部相差 < 8px 且时间文字仍可见。
