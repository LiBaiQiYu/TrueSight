# 出装/背包/走势数据规则

时间轴（出装路线、此刻背包、走势、KDA）只在**高级分析且录像解析成功**后显示；普通分析没有时间轴入口。

## 数据来源

| 区块 | 来源 |
|---|---|
| 购买 / 卖出 | `replay.focus.purchases`（秒级，含图纸）+ `replay.focus.sells`（真实卖出） |
| 此刻背包 | `replay.focus.items`：每个网络帧读取焦点英雄的 **6 格装备栏 + 1 格打野装备 + 3 格背包**，只在内容变化时记录快照 |
| 走势 / 等级 / 补刀 / KDA | `replay.series`：从录像实体流每 **5 秒**采样一次，覆盖全部 10 名玩家 |
| 技能 / 天赋顺序 | OpenDota `ability_upgrades_arr`（录像没有可靠的逐次升级时间） |
| 对位 / 分路 | OpenDota / STRATZ（属于名单元数据） |

`replay.focus.items` 读取英雄的 `m_hItems`：0–5 装备栏、6–8 背包、**16 打野装备（中立物品）**；9–15 是储物栏，不进入展示。卖出/使用/合成导致格子清空时，会写入 `focus.sells`（真实卖出）和 `focus.removed`（所有离开格子的物品，便于调试）。

`replay.series` 读取 `CDOTA_PlayerResource.m_vecPlayerTeamData`（K/D/A、等级）和 `CDOTA_DataRadiant/Dire.m_vecDataTeam`（净经济、补刀、反补、总经验、英雄伤害），按玩家槽位对齐；净经济/补刀/经验与 OpenDota 的分钟采样逐项核对过。

## 背包展示

- 固定 **6 装备栏 + 1 打野装备 + 3 背包**，空槽用虚线框显示；
- 装备栏 22px、打野装备 26px（金色强调）、背包 18px（更小、更淡）；
- 组标题分别为「装备栏」「打野装备」「背包」；悬停显示物品中文名；
- 消耗品、图纸、Aegis 等只要真的在格子里就显示；
- 中立物品的**强化槽**（`m_hItems.0017`，如「警觉」）暂不单独占格，避免破坏 6+1+3 布局。

## 走势展示

- `TimelinePoint` 同时保留分钟点和回放 5 秒点；有回放时图表、磁贴、10/20 分钟对位卡全部优先用 5 秒点；
- 图表横轴仍是分钟，但一条线最多 730 个点，曲线更细；
- KDA 磁贴显示当前时刻的 K/D/A（回放 K/D/A 来自实体流，助攻不再是“只有终局”）；
- 补刀/反补、等级、经验、净经济、英雄伤害均来自录像；
- 普通分析没有回放数据时，图表自动退回 OpenDota 分钟点（但时间轴本身不会显示）。

## 常见错误

- 高级分析报 `java 退出码 1: no snappyjava in java.library.path`：snappy 解压 native dll 的临时目录不可写（服务没有 TEMP/TMP 时 Windows 会回退到 `C:\Windows\System32`）。`server.py` 现在把 `java.io.tmpdir` 指到 `.cache/tmp`、`org.xerial.snappy.tempdir` 指到 `.cache/snappy`，`start.bat` 也会设置 TEMP；重启服务即可。仍报错时删除 `.cache/snappy` 再试，或检查该目录是否被杀软/权限限制。

## 已知边界

- 打野装备的**强化**（`m_hItems.0017`）暂不单独显示；
- 储物栏（`m_hItems.0009..0015`）不属于 6+1+3，不显示；
- 德鲁伊的小熊背包与本体分开显示为「本体 / 小熊」两组，数据来自回放 `focus.bearItems`；旧缓存没有小熊快照时服务器会自动重新解析；
- 录像内部类名和当前物品 key 不一致时按**版本化别名**映射：同一类名在不同 build 可能对应不同物品，不能全局硬编码；已确认 `Guardian_Shell` 在 build 10836 / 10939 对应 Defiant Shell（`item_defiant_shell`，不羁甲壳）；未知 build 不做跨版本猜测；
- 当前物品库确实没有的 key 不进入背包/出装路线，避免显示成“未知装备”；
- 只有真实售卖事件才标记「已卖出」；A 杖升级福佑、阿哈利姆魔晶/消耗品使用、德鲁伊装备交给小熊，分别标记「已升级为福佑」「已使用」「已交给熊」，不按卖出处理；
- 守卫组合（侦察·岗哨守卫）按成品时间向前找**最近的**侦查/岗哨守卫配对，不会拿很早以前的眼（例如 0:00 的出门眼）来聚合；
- 技能/天赋只有顺序，没有逐次升级时间；时间轴里标注为估算；
- 对位玩家的背包不显示，只有分析对象的完整 6+1+3。
